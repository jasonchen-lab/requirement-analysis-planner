# 需求分析规划MCP工具

这个目录包含敏捷超级个体实践框架中的需求分析与规划MCP工具。

## 目录结构

- `requirement_analysis_planner.js` - 核心模型和数据结构
- `requirement_analysis_planner_demo.js` - 演示代码
- `install_requirement_analysis_planner.js` - 安装脚本
- `requirement_analysis_planner_README.md` - 详细使用文档
- `examples/` - 示例模板文件
  - `business_objectives_template_example.md` - 业务目标文档示例
  - `user_stories_template_example.md` - 用户故事文档示例

## 快速开始

1. 运行安装脚本：
   ```
   node install_requirement_analysis_planner.js
   ```

2. 在Cursor AI中使用：
   ```
   请使用需求分析与规划MCP工具帮助我收集并分析项目需求
   ```

## 工具功能

- **结构化工作流程**：提供完整的需求分析阶段工作流程，从业务目标获取到迭代计划制定
- **引导式对话模板**：内置核心提问清单，帮助Cursor AI有效引导业务专家提供关键信息
- **思维工具集成**：包含产品愿景画布、用户故事模板、领域模型映射等专业思维工具
- **标准化输出**：定义统一的文档结构和输出模板，确保工作成果的一致性和完整性

详细说明请参考 `requirement_analysis_planner_README.md`
